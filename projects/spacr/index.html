spaCR

Spatial phenotype analysis of CRISPR-Cas9 screens.

spaCR segments cells, nuclei and pathogens in microscopy images, measures every object, and links the measurements to the guide RNAs sequenced from the same wells. It starts from plate images and FASTQ reads and ends with per-cell measurements, trained classifiers and a ranked list of genes.

  • Released 2026-10-09
  • Python 3.9–3.14

What spaCR does

Seven modules, run in order. Each one reads the previous module's output and writes its own into the same project folder. Segmentation, measurement, annotation and classification also run without sequencing data.

  1. ImportConverts microscope files into one folder layout per plate.Produces: Image folders and a project
  2. MaskSegments cells, nuclei, parasites and organelles with Cellpose models.Produces: Label masks for every field
  3. MeasureMeasures shape, intensity, texture and position of every object.Produces: measurements.db and single-object crops
  4. AnnotateLabels object crops in a keyboard-driven grid.Produces: Labels in the project database
  5. ClassifyTrains image models (ResNet, MaxViT) or measurement models (XGBoost, random forest).Produces: Checkpoints with held-out metrics, per-object scores
  6. Map barcodesDecodes row, column and guide barcodes from FASTQ reads.Produces: Guide counts per well
  7. RegressionEstimates guide and gene effects from scores and guide counts.Produces: Volcano plot and ranked hit list
  8. And moreDose-response, control charts, plaque and recruitment assays, image UMAP, batch correction, power and plate design, and a QC dashboard. See Assays and QC and Phenotypes.

Inputs

  • TIFF, OME-TIFF, ND2, CZI and LIF images, 2-D, volumetric and time series
  • Multi-well plates from any microscope that writes one of these formats
  • FASTQ reads with row, column and guide barcodes
  • Live folder watch for ND2, CZI, LIF and OME-TIFF files as they are written (alpha, off by default)
  • OME-Zarr and OMERO through optional extras

Organisms

  • Toxoplasma gondii in host cells: guide, recruitment, plaque and replication assays
  • Any cell type for segmentation, measurement and classification
  • Pages for other pathogens are in development and hidden by default

Outputs

  • An SQLite database per project: measurements, labels, predictions
  • Masks, crops and images as files on disk
  • Effect estimates, p and q values, diagnostics and run records
  • Figures as PNG, PDF, SVG or TIFF; one zip per figure with its data, statistics and a script that redraws it
  • AnnData export, and a vvvv export (alpha)

Models

16 published Cellpose-SAM and YOLO models with model cards: parasite vacuoles, plaques, plaque-assay wells, and cross-channel models that predict cells, nuclei or parasites from a single stain. Weights download from Hugging Face and are checked against a published checksum. See Models.

Ways to run it

  • Desktop appInstallers for Windows, macOS and Linux, or spacr after pip or conda.
  • Python APIEvery module is a function that takes a settings dictionary.
  • Command linespacr-run runs any pipeline headless on a workstation, server or cluster.
  • NotebooksJupyter notebooks for each step, from masks to regression, in the repository.
  • DockerCPU and CUDA images on GitHub Container Registry. See Docker.

Pipeline

One whole field followed through spaCR: HeLa cells infected with Toxoplasma, plate 2, well P08, field 16 of the MTOC screen, imaged with Hoechst and CellMask. Steps 1 to 4 use this field; step 5 is the hit list of the GFP-TSG101 example screen, because the MTOC screen's hits are not public.

  1. 1Image

    13 host cells and 54 vacuoles in this window of a 2000 × 2000 px field; Hoechst blue, CellMask grey.

  2. 2Mask

    Cell, nucleus and vacuole outlines: 37 cells, 44 nuclei and 130 vacuoles in the field.

  3. 3Measure

    Cells coloured by vacuole coverage (Measure): 9 of 13 above 0, up to 0.161.

  4. 4Classify

    XGBoost infection score from host features only; 8 of 13 cells above 0.5, field not used for training.

  5. 5Hit

    Four-plate GFP-TSG101 screen: 414 genes, 4 called at q < 0.05; GRA14 is the hit.

Data: Hoechst and CellMask images with published cell, nucleus and vacuole masks from cross-channel-cell-from-hoechst, cross-channel-nuclei-from-cellmask and cross-channel-toxoplasma-from-cellmask (CC BY 4.0). Measure and the XGBoost classifier ran in spaCR on CPU over 52 fields of the same plate. Hit list: OLS regression of spacr-example-screen.

  • MaskSegments cells, nuclei, pathogens and organelles with Cellpose models.
  • MeasureShape, intensity, texture and position of every object, and a crop of each, in SQLite.
  • AnnotateLabels object crops in a grid with keyboard shortcuts.
  • ClassifyTrains image or measurement classifiers and stores held-out performance with each checkpoint.
  • Map barcodesAssigns sequencing reads to wells and guide RNAs.
  • RegressionEstimates guide, gene and condition effects with intervals and a ranked hit list.

How to read these scores
  • Precision is the share of objects the model reported that match a reference object; low precision means false detections. Recall is the share of reference objects the model found; low recall means missed objects.
  • F1 is the harmonic mean of precision and recall, so it is high only when both are. Either alone can look near-perfect: a model that reports one obvious object has high precision, and one that reports every dark blob has high recall.
  • IoU (intersection over union) is the overlap between a predicted and a reference object divided by the area the two cover together. F1 at IoU 0.5 counts an object as found when that ratio reaches 0.5.
  • Average precision at one IoU threshold is true positives divided by true positives, false positives and false negatives together. mAP averages it over several thresholds, so it also rewards outlines that fit closely.
  • AJI (aggregated Jaccard index) adds up the overlap of every matched pair and divides it by their combined area plus the area of unmatched objects, so merged, split and missed objects all lower it.
  • Dice is twice the overlap divided by the predicted area plus the reference area.
  • The grey bar is the baseline named in the column header, scored on the same test images: stock Cellpose-SAM without fine-tuning, or an earlier model where no stock model has the class.
  • The held-out test set is images kept out of training and used only for scoring.

Plaque-well detection

The plaque module first finds each well in a plate image or published figure and then segments plaques inside it; the detected well also gives the diameter that makes plaque areas comparable across microscopes. Stock YOLO has no plaque-well class, so each detector is compared with the one before it: on 129 held-out test images v2 scores mAP50 0.946 against v1's 0.884, with 49 false boxes on no-well images against 152.

Cross-channel models

Cross-channel models predict one object type from another channel's image, so a stain can be left out and its channel used for another marker: cells from Hoechst alone, nuclei from a cell mask alone, and Toxoplasma vacuoles from either. Stock cpsam_v2 does not do this: on held-out fields its F1 at IoU 0.5 is 0.301, 0.201, 0.022 and 0.002 against 0.870, 0.888, 0.606 and 0.569 for the four trained models.

Permutation tests

spaCR's guide-permutation analysis (Regression, nonparametric inference) on the screen's MaxViT per-cell scores: each gene's and each guide's partial correlation with the well-mean score, given plate, row and column, against 2,000,000 within-plate Freedman–Lane permutations (seed 0). Layout as in the preprint's Figure S7 (panels R and S). With the example's shipped settings, control wells and guides stay in, so the numbers differ from the preprint, which excluded them and filtered wells. Data: spacr-example-screen, settings from spacr-example-hit.

Classification

Classifiers that tell the screen's control wells apart, trained and explained with spaCR on CPU: an XGBoost model on per-cell measurements and a small image model (MobileNetV3-small, 8 epochs) on single-cell crops. Column 1 wells carry guides against SAG1 (negative control) and column 2 wells against GRA14 (positive control). Wells are held out whole, so no test cell shares a well with a training cell. The installers include their own Python, so Conda is not needed. Files from the v1.5.1.4 release.

  • Windows 10 and 11 spaCR-1.5.1.4-Windows-Online-Setup.exe Download 244 kB
  • macOS 11 or later, Intel and Apple silicon spaCR-1.5.1.4-macOS-Universal-Online.pkg Download 390 kB
  • Linux x86-64 spaCR-1.5.1.4-Linux-x86_64-Online.run Download 236 kB

Checksums: SHA256SUMS.txt. Older installers and troubleshooting: installer documentation.

Docker

Images for Linux x86-64 on GitHub Container Registry, one per release: 1.5.1.4 and 1.5.1.4-cpu for CPU, 1.5.1.4-cuda12.4 for NVIDIA GPUs, and latest. They run the command-line pipelines; the desktop app is not included.

CPU: list the pipelines

docker run --rm ghcr.io/einarolafsson/spacr:1.5.1.4 spacr-run --list

NVIDIA GPU (needs the NVIDIA Container Toolkit)

docker run --rm --gpus all ghcr.io/einarolafsson/spacr:1.5.1.4-cuda12.4 spacr-run --list

Mounting data and models, settings files and full pipeline commands: container guide.

Biography
Einar B. Olafsson is a Research Investigator in the Department of Microbiology & Immunology at the University of Michigan. He studies how Toxoplasma gondii interacts with the cells it infects, combining CRISPR screening, high-content microscopy and AI-based single-cell image analysis to link genetic perturbations to spatial cellular phenotypes. He created and maintains spaCR. He studied biology and immunology at Uppsala University and received his PhD in Molecular Biosciences from Stockholm University, with a thesis on signalling in Toxoplasma dissemination by infected immune cells.
