spaCR

Spatial phenotype analysis of CRISPR screens.

What it does

spaCR segments and measures single cells in microscopy images, integrates per-object phenotypes with sequencing-derived guide abundance, and estimates which genes are associated with phenotypic changes. Starting from plate images and FASTQ reads, it produces per-object measurements, trained classifiers, per-guide and per-gene effect estimates, and a ranked hit list.

The segmentation, measurement, annotation and classification modules also run without a sequencing arm. Images, masks, crops, measurements, annotations, predictions, barcodes and well identifiers live in one SQLite project. It runs as a desktop application or headlessly on a workstation, server or cluster.

  • Mask segments cells, nuclei, pathogens and organelles with Cellpose.
  • Measure writes morphology, intensity, texture, spatial and colocalization features, together with object crops, to SQLite.
  • Annotate labels crops in a keyboard-driven grid and supports active-learning queues.
  • Classify trains image or measurement-based models and records held-out performance with each checkpoint.
  • Map Barcodes maps FASTQ reads to wells and gRNAs, with abundance, collision and coverage QC.
  • Regression estimates guide, gene, condition and control effects with model families suited to continuous, fractional and count responses.

Install spaCR 1.5.1.4

Desktop installers

They bundle their own Python; Conda is not required. From the v1.5.1.4 release.

  • Windows 10/11
    spaCR-1.5.1.4-Windows-Online-Setup.exe    244 kB
  • macOS 11+ (Intel and Apple silicon)
    spaCR-1.5.1.4-macOS-Universal-Online.pkg    390 kB
  • Linux x86-64
    spaCR-1.5.1.4-Linux-x86_64-Online.run    236 kB

Checksums: SHA256SUMS.txt. Older installers and the troubleshooting guide are in the installer docs.
