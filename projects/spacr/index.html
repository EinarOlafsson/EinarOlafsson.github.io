Overview

spaCR segments cells and their compartments in microscopy images, measures each object, and links the measurements to the guide RNAs sequenced from the same wells. The input is plate images and FASTQ reads. The output is per-object measurements, trained classifiers, per-guide and per-gene effect estimates and a ranked list of genes.

The segmentation, measurement, annotation and classification steps can also be used without sequencing data. All results for a project are stored in one SQLite database. spaCR runs as a desktop application or from Python on a workstation, server or cluster.

  • MaskSegments cells, nuclei, pathogens and organelles with Cellpose models.
  • MeasureComputes morphology, intensity, texture, spatial and colocalization features and saves object crops.
  • AnnotateLabels object crops in a grid with keyboard shortcuts.
  • ClassifyTrains image or measurement classifiers and stores held-out performance with each checkpoint.
  • Map barcodesAssigns sequencing reads to wells and guide RNAs and reports abundance and coverage.
  • RegressionEstimates guide, gene and condition effects with models for continuous, fractional and count responses.

Published models

Each figure shows one real image and the objects that spaCR's published models detect in it. Drag the divider to compare the input with the outlines, and use the check boxes to show or hide a class. Counts are objects in the image shown. Weights resolved through spaCR's model zoo (nightly, 2026-10-10) and run with Cellpose 4.2.1.1 on CPU.
