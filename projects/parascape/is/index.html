ParaScape

Vísbendingar um gen í Toxoplasma gondii og Plasmodium falciparum á einum stað.

ParaScape sameinar tjáningu, hæfniskimanir, staðsetningu, próteineiginleika, víxlverkanir og skýringar úr fræðiritum. Notaðu það til að fletta upp geni, rannsaka frambjóðendur úr skimun, bera saman hópa gena og velja gen til frekari tilrauna. Meðfylgjandi kort innihalda 8.140 gen úr T. gondii og 5.720 gen úr P. falciparum, sem eru skoðuð hvort í sínu lagi.

  • Útgáfa 0.0.4.0
  • Gefin út 2026-10-30
  • Python 3.10 or newer

Hvað það gerir

  • Kanna genLeitar í auðkennum, táknum og lýsingum og sýnir síðan vísbendingarnar úr heimildunum.
  • Spá fyrir um eiginleikaBer saman spár fyrir frátekin gen áður en það flokkar ómerkt gen, og heldur skyldum genum í sama matshópi.
  • Bera saman skimunTengir CSV- eða TSV-skrá á genastigi við fyrirliggjandi vísbendingar og heldur óleystum auðkennum sýnilegum.
  • 39 aðferðirNefndar leiðir til að breyta sameinuðu gögnunum í fullyrðingu, hver með leiðbeiningum og sjálfsprófi gegn stokkuðum gögnum.

Staðsetningar á kortinu koma úr greypingu valinna eiginleika: nálæg gen hafa svipuð inntaksgögn, sem eitt og sér sýnir hvorki sameiginlegt hlutverk né efnislega víxlverkun. Leitareinkunnir hjálpa til við að forgangsraða genum; þær eru ekki staðfesting með tilraunum. Genatöflur og net fylgja pakkanum og virka án nettengingar; 130 skráð gagnasöfn eru talin upp ásamt heimildum sínum í gagnasafnaskránni.

Kanna skimun

  1. Veldu lífveruna undir File → Species.
  2. Leitaðu að auðkenni gens. Fyrir T. gondii bætir File → Import data niðurstöðum skimunar þinnar við.
  3. Litaðu og síaðu kortið eftir mælingunum sem þú vilt bera saman.
  4. Smelltu á gen til að lesa vísbendingar um það og skoða hverja tegund tengsla fyrir sig.
  5. Veldu hóp með snöru eða pensli og fluttu síðan genalistann út til frekari athugunar.

Krefst Python >=3.10, skjás og OpenGL. Greiningar keyra á örgjörvanum; pip install "parascape[gpu]" bætir við stuðningi við NVIDIA-skjákort á Linux x86-64 með rekli fyrir CUDA 12.

Úr spaCR

Í skjáborðsforriti spaCR setur ParaScape-reiturinn á Toxoplasma-síðunni upp ParaScape í eigin Python-umhverfi og opnar það sem sérstakt forrit (merkt alfa í spaCR). Til að skoða niðurstöður spaCR í ParaScape skaltu flytja töflu á genastigi út úr spaCR og flytja hana inn með File → Import data.
